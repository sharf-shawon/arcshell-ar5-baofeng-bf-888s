# Security Policy

## Supported Versions

Currently, only the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability (e.g., a dangerous frequency configuration or a malicious link), please do not open a public issue. Instead, report it privately to the repository maintainer.

**Maintainer Contact:** [sharf.shawon@gmail.com] (Placeholder)

We will respond within 48 hours and provide a fix as soon as possible.
